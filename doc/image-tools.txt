*image-tools.txt*  Independent image previews for Neovim

REQUIREMENTS                                               *image-tools*

Neovim 0.12+, termguicolors, and Kitty 0.28+ in a direct terminal session.
PNG needs no converter. Other raster formats and PDF require ImageMagick;
PDF conversion also needs Ghostscript. SVG uses rsvg-convert if available,
otherwise ImageMagick's MSVG renderer. PDF file buffers additionally need
Poppler's pdfinfo for page counts; floating/picker previews use the first page.
Multiplexers (TMUX/ZELLIJ) are rejected. Other terminals, SSH and GUI frontends
have not been validated. force=true bypasses only terminal-name detection, not
the Neovim version, attached UI, termguicolors or multiplexer checks.

SETUP                                                      *image-tools-setup*
>
  require("image_tools").setup({
    auto_preview = true,
    convert_concurrency = 2, -- simultaneous converter processes
    treesitter = true, -- LaTeX/Typst parsers, with automatic Lua scanner fallback
    latex = { max_reference_lines = 64, max_reference_bytes = 16 * 1024 },
    buffer = { enabled = true }, -- intercept binary image/PDF files
    pdfinfo = "pdfinfo",
    pdf_density = 144,
    position = "bottom_right", -- default: "cursor"
    transport = "auto", -- prefer local file transfer; fall back to direct data
    terminal_cache = { max_images = 32, max_bytes = 64 * 1024 * 1024 },
    disk_cache = { enabled = true, max_files = 256, max_bytes = 512 * 1024 * 1024 },
    insert = { directory = "Figures", mode = "copy",
      insert_strategy = "insert_line_after", prompt_for_file_name = false },
    max_width = 60,
    max_height = 30,
    border = "rounded",
    magick = "magick",
    rsvg = "rsvg-convert",
    convert_timeout = 10000,
    terminal_timeout = 1500,
    max_bytes = 32 * 1024 * 1024,
    max_dimension = 16384,
    max_pixels = 64 * 1024 * 1024,
    max_scan_lines = 10000,
    cell_size = { width = 10, height = 20 },
    force = false,
  })
<
Merely requiring the module does not register handlers or mappings.
Disable Snacks.image to avoid competing image handlers and mappings.
Load with lazy=false to register file-buffer handlers before startup files are
read. The default cache is stdpath("cache") .. "/image-tools".
position = "bottom_right" anchors the float to the editor's bottom-right corner,
above the command line and status line. "cursor" places it near the cursor.

COMMANDS                                                   *:ImagePreview*

:ImagePreview [path]    Preview a file, or the image reference under the cursor.
                       Outside references, preview the first image on the line.
                       File paths are literal: spaces work without quotes.
                       Explicit relative paths use cwd; Markdown paths use
                       the document directory or configured root.

:ImagePreviewClose                                         *:ImagePreviewClose*
                       Close the float and cancel pending work. Uploaded pixels
                       remain in the bounded terminal cache for reuse.

:ImagePreviewClearCache                                    *:ImagePreviewClearCache*
                       Close floating, picker and file-buffer views and free
                       all image-tools terminal images. File buffers remain
                       attached; buffer/tab entry, resume, opening or reload
                       resumes their canvases.

:ImageCacheClear                                           *:ImageCacheClear*
                       Delete unused converted disk images, preserving files
                       held by active preparation handles.

:ImagePreviewToggle                                        *:ImagePreviewToggle*
                       Toggle automatic current-line preview.

:checkhealth image_tools
                       Check the terminal and image conversion tools.

API                                                        *image-tools-api*

setup(opts)            Configure the plugin; repeated setup replaces handlers.
preview(path, opts)    Preview a file. opts.silent suppresses notifications.
hover(opts)            Preview the image reference under the cursor, falling back
                       to the first image on the current line.
close()                Close preview; safe to call repeatedly.
clear_cache()          Close preview and release all owned terminal images.
clear_disk_cache(cb)   Clear unused disk conversions asynchronously; cb receives
                       a status table (removed, protected, files, bytes, error).
toggle()               Toggle automatic preview; returns its new state.
status()               Return configured, auto_preview, path, window, transport
                       and terminal_cache statistics, plus buffer state,
                       disk_cache settings/path, conversion_queue, media and
                       treesitter diagnostics when configured.
insert(paths, opts, cb) Import/reference one path or a batch; returns cancellation.
                       With nil paths, prompt for a file.
paste(opts, cb)         Paste a macOS clipboard image; returns cancellation.
pick(opts, cb)          Open Snacks.picker; returns a picker or nil on failure.
snacks_preview(ctx)    Custom Snacks image previewer with regular file fallback.
open(path)             Open an image/PDF file buffer; returns ok, error.
page(n)                Select a PDF page; reject out-of-range values.
next_page(delta)       Move by delta (default 1); clamp to the first/last page.
reload()               Reload the current image/PDF buffer and metadata.

See README.md for resource limits, caching and custom path resolution.
Before setup, status() returns configured=false, auto_preview=false and
transport="auto". Calling it does not initialize the plugin.

Automatic preview follows cursor lines. The cursor need not be inside the image
link. The reference under the cursor takes priority; outside all references,
the first image on the row is used. Errors in a selected destination do not
fall back to another image. Moving to another image changes the preview;
movement within the same reference, Insert mode and edits that preserve its
source keep the window and pending conversion. Markdown/Typst references cover
one row; LaTeX references may cover several. Leaving that row range closes the
preview and entering another image row starts a new one.

TRANSPORT                                                  *image-tools-transport*

"auto" tries Kitty t=f file transmission locally and t=d direct data when
SSH_CONNECTION or SSH_TTY is nonempty. A file failure/timeout falls back to direct
data. "file" forces files and reports failures; "direct" forces inline data.
terminal_timeout (default 1500 ms) bounds each upload/placement response wait.
Shared memory is not implemented; real SSH/other terminals remain unvalidated.

Terminal cache keys include path, inode, size and nanosecond mtime/ctime.
Reopening only sends a placement request. If Kitty has evicted the data, it is
uploaded again when no other view still owns it. Otherwise the affected view
reports an error; reload to retry. Inactive entries use LRU eviction, with default
limits of 32 images and 64 MiB estimated decoded RGBA bytes. Oversized images
are not retained.
max_images = 0 disables retention. Setup, suspend and exit release owned images.

SCOPE                                                      *image-tools-scope*

PNG, JPG, JPEG, WebP, AVIF, HEIC, GIF (first frame), BMP, TIF/TIFF, PDF and SVG
previews. Converted previews fit within 1920x1080 at default zoom; native PNG dimensions are
preserved and validated against max_dimension/max_pixels. Floating previews
do not upscale; picker and file-buffer previews can upscale to fit their pane.
Complete same-line Markdown inline images, angle-bracket destinations, quoted
titles, escaped punctuation and percent-encoded paths. Code blocks/spans are
excluded. LaTeX, Typst, independent insertion, macOS clipboard paste, Snacks
picker integration and read-only image/PDF file buffers are supported below.
Remote URLs, multiline Markdown
calls, formula previews and inline rendering inside document text are unsupported.
Insertion has no dependency on image-insert.nvim.

DISK CACHE                                                *image-tools-disk-cache*

Converted PNGs are stored under cache (default stdpath("cache") .. "/image-tools").
Automatic asynchronous eviction defaults to 256 files / 512 MiB. Active handles
pin files and may temporarily exceed these limits. disk_cache.enabled=false
disables automatic eviction; :ImageCacheClear still removes unused conversions.
Cleanup considers only 64-hex-digit PNG names directly in that directory; other
files, symlinks and conversion temporaries are excluded. Access order is tracked
in memory, with modification times providing the initial order after restart.
Disk conversions are independent of the terminal pixel cache.

INSERTION                                                 *image-tools-insert*

:ImageInsert [path]                                          *:ImageInsert*
Copies a file into insert.directory (default Figures beside the saved document)
and adds a relative reference. :ImageInsert! references it without
copying. insert(path_or_paths, opts, callback) returns a cancel function. opts:
directory, root, mode (copy/reference), filename, alt, prompt_for_file_name and
insert_strategy (insert_before/insert_after/insert_line_before/insert_line_after).
The source buffer and extmark insertion position survive asynchronous prompts.
Collisions add suffixes without overwriting. Failure/cancellation removes newly
imported files; text undo retains them for reuse. A batch is inserted as one edit.
The document must be saved and modifiable. Unloading/deleting or renaming it,
changing its filetype, or disabling modifiable invalidates a pending import;
readonly alone does not block insertion. File imports preserve bytes and format.

:ImagePaste                                                  *:ImagePaste*
Reads the macOS clipboard with pngpaste (brew install pngpaste).
paste(opts, callback) accepts the insertion options plus format (png/jpg/webp/avif)
and quality (default 75). PNG is the default; conversions require ImageMagick.
Clipboard resources are always copied. Empty clipboard, missing tools and failed
conversion cause no insertion; cancellation kills subprocesses and cleans temp files.
The read timeout defaults to 5000 ms (per-call clipboard_timeout); conversion
uses convert_timeout. A per-call pngpaste option can replace the executable.

PICKER                                                    *image-tools-picker*

:ImagePick                                                   *:ImagePick*
pick(opts, callback) requires Snacks.picker. opts.insert overrides
insertion defaults; opts.picker overrides file picker options. Confirmation
imports selected files at the original extmark position. Closing cancels.
Images render in the existing preview pane with this plugin's transport/cache.
Images scale up/down to fit the pane and align to its top-left, preserving
their aspect ratio.
Pane/terminal resizing refreshes placement and reuses pixels. Floating preview
max_width/max_height do not limit picker size; protocol coordinates cap each axis
at 297 cells. Selection changes cancel stale conversions; closing frees images
and handlers.
For regular file pickers/explorer, configure Snacks picker.preview as:
>
  function(ctx) require("image_tools").snacks_preview(ctx) end
<
Keep Snacks.image disabled. Non-image entries use the regular Snacks file preview.

LATEX                                                     *image-tools-latex*

LaTeX and Typst use Neovim's Tree-sitter buffer parser by default. Install the
latex/typst language parsers; nvim-treesitter is not a required dependency.
Missing parsers, incompatible queries, parsing failures or syntax errors in
preceding context fall back to the cached Lua scanner. Valid empty results do not
fall back. Set treesitter=false to always use the scanner.
Parses may yield asynchronously; pending work does not start a
lexical scan. Completion requires the same buffer/window/byte column/text version;
row movement inside the same pending LaTeX range is allowed. Root parsing may
cover the whole document; capture traversal advances through the requested row.
LaTeX argument decoding can look ahead within its limits and max_scan_lines.
Edits and parser change ranges invalidate the affected suffix, retaining valid
prefixes.
Path resolution stays live. status().treesitter and :checkhealth image_tools
report backend/fallback reasons, parse/index timing, hits and indexed rows.
Parse timing includes time yielded to the event loop.
Markdown uses its existing scanner. Formula preview is not included.

tex/latex/plaintex: literal \includegraphics[options]{path}, starred form,
\detokenize paths, single-line literal \graphicspath declarations, and omitted
PDF/PNG/JPG/JPEG extensions. Comments, \verb and verbatim/lstlisting/minted/comment
environments are excluded. Commands and optional arguments can span lines; filename contents
must stay on one line. Macros are not expanded. Any row covered by a complete
reference (including commented option rows) can preview it; movement within that
range retains the window/conversion, and leaving closes it.
latex.max_reference_lines (64) / max_reference_bytes (16 KiB) bound each reference;
lookahead also respects max_scan_lines. Both Tree-sitter and Lua fallback support
these ranges. Editing any covered row invalidates the full reference. Unclosed,
oversized references and filenames split over lines are not guessed.
Resolution: configured root (string/function), b:vimtex.root, document directory.
Insertion requires graphicx and emits width=\linewidth with a detokenize path.
Imports accept PNG/JPEG/PDF and sanitize TeX-special filename characters. Unsafe
reference/directory paths fail and roll back. PDF preview uses the first page;
file buffers support paging. ImageMagick must have Ghostscript support.

TYPST                                                     *image-tools-typst*

Literal same-line #image("path", ...) and image("path", ...) in code, including
inside multiline #figure bodies. Code strings, raw text and nested comments are
excluded. Dynamic paths and multiline image calls are not evaluated.
Relative paths resolve beside the document; /paths use the configured project root
(or document directory). Configure root to match typst compile --root.
Insertion uses document-relative paths and width: 100%; PNG/JPEG/GIF/WebP/SVG/PDF
imports are supported. PDF embedding requires a supporting Typst version (0.15.1
tested). Outside-project direct references fail: copy or configure root instead.
SVG preview prefers rsvg-convert (rsvg option), then ImageMagick's internal MSVG
renderer. Complex SVG rendering may differ with MSVG. Originals are unchanged.


FILE BUFFERS                                              *image-tools-buffers*

buffer.enabled (true by default) installs BufReadCmd for common binary images
and PDFs. Use lazy=false to register before startup files are read.
:ImageOpen path                                               *:ImageOpen*
Opens an explicit file viewer (including SVG). Normal :edit SVG
stays editable unless svg is added to buffer.formats. Automatic takeover skips
already loaded modified buffers. Original files stay unchanged; viewers use
readonly, nonmodifiable nofile buffers and cannot write placeholder text to disk.
A nonfocusable Kitty canvas belongs to each regular window, aligned top-left
beneath a filename/page header. Splits, resizing, tab switching and closing are
handled independently. Exiting/suspending frees images and cancels requests.
PDF page selection is shared by splits showing the same buffer; placements and
viewport sizes remain independent.

PDF buffers require magick with Ghostscript plus pdfinfo (brew install poppler).
]p / [p: next/previous PDF page (counts supported).
:ImagePage N: go to a page; reject out-of-range values.        *:ImagePage*
:ImageNextPage: move forward (counts supported).             *:ImageNextPage*
:ImagePreviousPage: move backward (counts supported).         *:ImagePreviousPage*
Relative movement clamps to the first/last page.
r / :ImageReload: reread the file and metadata.               *:ImageReload*
PDF conversion uses pdf_density=144; converted/uploaded pages are cached separately.
File changes are checked on buffer/window/focus events; r forces a refresh.
Failures (missing tools, corrupt/oversized files, unsupported terminals) display
readable errors in the file buffer. buffer.enabled=false disables automatic
interception; :ImageOpen still works. buffer.formats controls automatic extensions.

API: open(path), page(n), next_page(delta), reload(), status().buffer.

Converter processes share a FIFO queue controlled by convert_concurrency
(default 2). Queued cancellation does not spawn a process; running cancellation
holds its slot until exit. PNG reads and cache hits bypass the queue.
status().conversion_queue reports active and queued processes.

Floating, picker and file-buffer previews share terminal pixel data per runtime.
Each view has an independent virtual placement id and size. Closing a view
releases only its placement; terminal_cache limits apply to the shared pool.
Cache statistics are runtime-wide; placements counts active acknowledged views.
Setup replacement and explicit clearing free all shared terminal pixels.

DEVELOPMENT                                               *image-tools-development*

Run sh tests/run.sh. Its commented groups cover API/lifecycle, media/transport,
insertion/picker, document scanners/parsers, file buffers and PTY/TUI tests.
Suites are grouped under tests/core, document, media, render, terminal and
workflow. Shared assets and demo.md live under tests/fixtures. tests/tui/run.py
launches the TUI Lua scenarios; run python3 -u tests/tui/run.py to isolate them.
Each Lua test uses a fresh Neovim process without user config or plugin autoloading.
Temporary fixtures, caches and logs are removed on exit; the first failure stops
the run. Status labels use cyan [run], yellow [skip], green [done] and red [fail].
Redirected output, unset/dumb TERM, or NO_COLOR disables colors.

The suite requires Neovim and magick with Ghostscript for PDF conversion.
IMAGE_TOOLS_PARSER_ROOT enables dedicated latex/typst parser suites;
IMAGE_TOOLS_SNACKS_ROOT enables Snacks integration. Compiler checks run only when
pdflatex/typst are available; Python 3 enables Unix PTY tests with a simulated
Kitty responder. Successful runs can contain skips; check the reported coverage.
RGB checks accept semicolon/colon SGR and verify actual image/placement colors;
extended underline support may come from terminfo or a replied capability probe.
Visible pixels still need a real Kitty check. tests/manual/clipboard_native.lua
is a separate opt-in test with a prepared system clipboard; the runner uses
fake clipboard tools and an explicit suite list that excludes manual tests.

Floating previews check source versions on focus gain and cursor idle, including
external rewrites and removal. `:ImageReload` / `reload()` refresh the current file
viewer, or the floating preview when called from its owning document. Unchanged
sources retain their placements; superseded asynchronous results are discarded.

Markdown reference images: ![alt][id], ![id][], ![id]. Definitions may follow
uses and must be complete on one line, within max_scan_lines. Labels ignore case
and collapse whitespace; the first definition outside code wins. Image wikilinks
![[path.png|label]] use literal document-relative paths, without vault search.

Image/PDF viewer controls: `+` / `-` zoom by a factor of two, `0` fits the
window, `1` uses native prepared-pixel scale, and arrow keys pan by five terminal
cells (counts supported). `:ImageZoom fit|native|in|out|FACTOR`, `zoom(value)`,
`:ImagePan X Y` and `pan(x, y)` expose the same controls. Numeric zoom is relative
to fit and ranges from 0.125 to 8. Zoom resets pan; pan clamps to image edges.
Each visible split retains independent controls across resize/reload/page changes;
leaving its buffer resets that window's controls. Cropped placements reuse uploaded
pixels. PDF and other converted formats prepare larger rasters when zoomed in; PDF
density and output bounds scale together, bounded by source/output limits and the
existing conversion queue. Native scale refers to the prepared raster, including
configured PDF density. Original files are unchanged.

Set `insert.deduplicate = true` (default false), or pass `deduplicate = true` to
insertion/paste, to reuse byte-identical files with the same extension in the
configured destination directory. Reuse takes precedence over the requested
filename; the directory is not searched recursively. Reads/hashing are bounded
by max_bytes; symlinks are excluded. Cancellation or failed insertion removes
only files created by that transaction, preserving reused files.

`:ImageCheckAssets` opens a quickfix report of missing references and possibly
unused image files in the current document's import directory. It supports
Markdown, LaTeX and Typst literal references, with the same syntax exclusions and
max_scan_lines limit as preview. A truncated scan is marked in the report.
"Possibly unused" only means unused in this document: shared resources may be
referenced elsewhere. Directory inspection is nonrecursive and excludes symlinks.
No files are deleted. `check_assets(opts, callback)` returns a cancel function;
the callback receives `(error, report)` with `missing`, `unreferenced`, `directory`,
`document`, `scanned` and `truncated`. Edits/rename/unload reject stale inspection.

VIEWER KEYMAPS                                         *image-tools-keymaps*

Configure buffer.keymaps by action; unspecified actions keep default keys. Set
an action to false, or the whole keymaps option to false, to disable mappings.
Existing user buffer-local mappings take precedence; reconfiguration removes
only still-owned plugin mappings.

Actions/defaults: reload=r, info=i, zoom_in=+, zoom_out=-, fit=0, native=1,
pan_left=<Left>, pan_right=<Right>, pan_up=<Up>, pan_down=<Down>, next_page=]p,
previous_page=[p. The page actions are PDF-only. Commands remain available.

:ImageInfo                                                    *:ImageInfo*
    Show source path/format/bytes, prepared raster dimensions, readiness, PDF
    bounds, zoom, terminal-cache counters and disk-cache directory. info() returns
    the same metadata plus crop; absent dimensions are pending. No conversion is
    started. stage is preparing, placing (waiting for terminal acknowledgement),
    ready or failed. Without an active viewer, the most recent failed floating
    request is returned with last_error=true, error and error_stage. Diagnostics
    survive close and retain no image resources; setup resets them. Without a
    viewer or retained failure, info() returns nil and an error.

preview_loading_delay defaults to 300 milliseconds. Pending floating previews
show a line-end loading hint after this delay; success, failure or cancellation
removes it. Set to 0 to disable hints. Automatic failures remain silent.

Configured magick, pdfinfo, rsvg and insert.pngpaste executables are checked by
checkhealth. The Ghostscript hint checks gs on PATH; ImageMagick selects its own
PDF delegate.
